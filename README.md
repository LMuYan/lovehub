# 史晓维专属 · 浪漫逗趣与心动网站 ❤️

> 张博暄 为 史晓维（老婆/宝宝）精心定制的专属浪漫前端应用。

## 🌟 核心特色

1. **今日份小祖宗心情打卡机**：针对宝宝的疲惫、想吃好吃的、想咬人、想老公等心情，提供专属小张急救处方。
2. **彩虹屁无限扭蛋机**：随时抽取来自张博暄的走心与幽默夸奖。
3. **求生欲大考验（逃跑按钮）**：永远点不到的“错误选项”，只能选史晓维是全宇宙最可爱的小仙女！
4. **女王特权心愿兑换券**：免死金牌、深夜投喂、揉肩捏腿等卡券，支持在线一键核销，心电感应即刻生效。
5. **时光印记拍立得长廊**：3D可翻转相册卡片，记录点滴心动。
6. **慢递手写情书**：打字机逐字输出张博暄对史晓维的深情告白。
7. **全屏浪漫特效与音乐系统**：
   - 鼠标/触屏拖尾光尘
   - 点击满屏心形烟花
   - 右上角可一键切换“浪漫粉萌”与“璀璨星空流星雨”双模式
   - 内置 Web Audio API 柔和八音盒音乐盒，无需外部依赖即开即响

## 🚀 如何打开与浏览

- **本地直接打开**：直接双击 `index.html`，即可在任何主流浏览器（Edge、Chrome、Safari等）中畅快体验。
- **手机查看**：如果在同一局域网下，可用本地轻量服务器（如 VS Code Live Server 或 `python -m http.server`）用手机扫码访问。

## ⚙️ 如何自定义内容 (`js/config.js`)

所有的姓名、昵称、纪念日、情书正文、夸夸词库、照片链接都在 `js/config.js` 中清晰集中管理：
- `startDate`：可修改为你们具体的相识或恋爱纪念日（格式：`"YYYY-MM-DD HH:mm:ss"`）。
- `memories`：可将图片链接替换为你们真实的合照或者生活趣照。
- `loveLetter`：可随时修改或增加更多想对她说的心里话。
